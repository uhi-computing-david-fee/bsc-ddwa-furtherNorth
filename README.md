# 🧭 FurtherNorth (Teaching Repo)

This repository contains the **FurtherNorth** project used in the module:

**Designing and Developing Web Applications (UG409759)**  
**BSc Computing**

It is a structured teaching example used to demonstrate:

- Responsive web design
- Translating desktop layouts into responsive interfaces
- CSS layout using **Grid** and **Flexbox**
- Responsive navigation patterns
- Semantic HTML
- Accessibility and appropriate use of **ARIA**
- Web quality and Lighthouse auditing
- Image optimisation
- Responsive images using **`srcset`** and **`sizes`**
- Image loading and performance strategy
- Progressive improvement of an existing front-end codebase

The application is intentionally introduced first as a **desktop-only design**, then progressively improved through responsive development, accessibility work and performance optimisation.

## 🌿 Branch Structure (Learning Timeline)

The `0-start` branch is the **starting point**, containing the original desktop-only version of FurtherNorth.

From there, each branch represents the project state at the **end of a teaching block or exercise**.

Branch progression:

| Branch Name | Content |
|---|---|
| `main` | Completed FurtherNorth application |
| `0-start` | Starting desktop-only version of the application |
| `1-responsive` | Responsive layout and navigation work completed |
| `2-quality` | Accessibility, web quality and image/performance optimisation completed |

If you fall behind or want to compare your work, switch to the appropriate branch.

---

## ⚠️ Notes

- Branches represent learning checkpoints, not separate production releases
- The starting version is intentionally incomplete from a responsive and performance perspective
- Responsive behaviour is introduced progressively rather than being present from the beginning
- Accessibility work focuses on semantic structure, appropriate ARIA and usable responsive navigation
- Performance work is driven by Lighthouse evidence rather than optimisation for its own sake
- Image optimisation includes resizing, compression, modern formats, responsive image delivery and loading strategy
- The final version is intended to demonstrate the full process of **design → responsive implementation → quality review → optimisation**
